# Timing and Easing — Lerry

- Entrance: ease-out.
- Exit: ease-in.
- On-screen motion: ease-in-out.
- Ambient loops: sine/ease-in-out.
- Character actions: choose duration based on action distance and narration pacing; do not force UI millisecond values onto full-scene animation.
- Use anticipation, then the main action, then follow-through/settle.
- Keep subtitle readability and narration timing above decorative motion.
